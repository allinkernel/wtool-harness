# 04 项目清单与变更导读

> 这篇回答："你几乎对所有仓库都做了修改，我完全无感知" —— 每个仓改了什么、怎么自己核对。

## 怎么自己核对（最快的办法）

**每个仓的迁移改动都只在一个提交里**，提交信息统一以 `迁移到 wtool 框架：` 开头：

```sh
cd ~/self/wtool

# 看某个仓被改了什么
git -C terminal/tmux show --stat HEAD     # 改了哪些文件
git -C terminal/tmux show HEAD            # 完整 diff

# 一次看完 8 个仓的改动摘要
for p in os/ubuntu shell/oh-my-zsh shell/zsh tools/repo terminal/tmux terminal/fzf; do
    echo "===== $p ====="
    git -C $p show --stat --oneline HEAD | head -12
done
```

**原历史一字未动**：每个仓都是「你的历史 + 最上面一个我的迁移提交」。
想看迁移前的样子：`git -C <项目> show HEAD~1`。

### `bootstrap/` —— 引擎（新写，不是迁移）

### `os/ubuntu/` —— 换源 + 装包

| 原 mytool | 现在 | 为什么 |
|---|---|---|
| 10 个静态文件（`ustc/*.sources.list`、`tuna/*.sources.list`，每个 Ubuntu 版本一份） | **删除**；改由引擎按 `/etc/os-release` 自动生成 | 不用再为每个版本维护一份；22/24/26 都能识别 |
| 旧的一行式 `deb https://...` 格式 | **deb822**（`Types:` / `URIs:` / `Suites:` …） | Ubuntu 24.04 起真正的源文件是 `/etc/apt/sources.list.d/ubuntu.sources` |
| `cp /etc/apt/sources.list` + 手工时间戳备份 | 备份到状态目录，`uninstall` 自动还原 | 可逆、可审计 |
| `sudo apt-get install -y ${base[@]} ...`（写死在 shell 里） | `provision/packages.yaml`（Ansible） | 幂等、可重跑、跨发行版；包列表本身还是原来那些 |
| 无 `readme` | 新增 `README.md`（原 `readme.md` 保留） | 说明改动 |

包列表来自原来的 `wsw_install.sh`（base / shell / editor / connect / compiler / libs / funny / search / graph 九组）。
原脚本里的 `assiidoc` 是 `asciidoc` 的笔误，迁移时**没有**包含。
